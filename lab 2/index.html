Docker Installation, Configuration & Running Images

Image Management, Port Mapping, Container Lifecycle & Host Cleanup

Step 1: Pull Docker Image

Download the official nginx web server image layers from Docker Hub to local repository storage.

docker pull nginx

Step 2: Run Container with Port Mapping

Launch a detached container process with port translation from host port 8080 to container port 80.

docker run -d -p 8080:80 nginx
docker run -d -p 8080:80 --name nginx-container nginx

Step 4: Stop and Remove Container

Send a graceful termination signal (SIGTERM) and purge container instance state.

docker stop & docker rm
